# @passui/tokens

Framework independent design tokens and shared styles. Both `@passui/react` and `@passui/tanstack` consume this package, so it must not import from either of them. Root rules in `../../AGENTS.md` apply.

## Stack

- **Language**: TypeScript source in `src/`, plain CSS in `styles/`
- **Key dependencies**: `tailwindcss` ^4 (peer), `tw-animate-css`
- **Tests**: Vitest, in `test/`

## Commands

```bash
bun run --filter @passui/tokens generate   # rewrite theme.css from src/
bun run --filter @passui/tokens typecheck
bun run --filter @passui/tokens test
bun run --filter @passui/tokens publish:check
```

## Conventions

- `theme.css` is generated by `scripts/generate-css.ts` from `renderThemeCss()` in `src/theme-css.ts`. Change the token in `src/`, then run `generate`. Never edit `theme.css` by hand.
- `styles/styles.css` is the single stylesheet apps import (`@passui/tokens/styles.css`). It pulls in Tailwind, the theme, `utilities.css`, `base.css` and `typeset.css`.
- Scrollbar chrome stays hidden in `styles/base.css` while scrolling keeps working. Do not reintroduce visible scrollbars.
- Use the `text-*` type scale tokens, never raw Tailwind sizes (see `../ui/AGENTS.md`).
- Each token group has its own subpath export (`./color`, `./motion`, `./layout`, `./accent`, `./typography`, `./theme-css`). Add new groups to `exports` in `package.json`.

## Key files

- `src/index.ts`: public entry point
- `src/theme-css.ts`: builds the generated CSS
- `test/tokens.test.ts`: token and generated CSS checks
