# Vaul constants

Drawer and Sheet use the release curve (`cubic-bezier(0.32, 0.72, 0, 1)`) and the
page scale values (26 px top offset, 8 px radius) read from
[Vaul](https://github.com/emilkowalski/vaul) 1.1.2, provided under the MIT licence.
Passui does not bundle Vaul; the gesture engine is `@zag-js/drawer`.
